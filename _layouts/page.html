The banner photograph is rendered here, from front matter, instead of being an inline markdown image at the top of every page's body. Order is title-then-banner, matching the design system's own ui_kits/website/SiteShell.jsx. alt is empty on purpose: these photographs are decorative and carry no text, so announcing them would only interrupt a screen reader.
