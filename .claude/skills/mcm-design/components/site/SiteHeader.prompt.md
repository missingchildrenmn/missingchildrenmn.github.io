Use SiteHeader at the top of every missingchildrenmn.com page recreation.

```jsx
<SiteHeader current="Resources" links={[{label:'About MCM'},{label:'Blog'},{label:'Child Safety'},{label:'Contact'},{label:'Missing Child'},{label:'Resources'},{label:'Support'}]} />
```

Nav order on the live site is alphabetical (Jekyll page order). The header collapses to a hamburger panel under 768px.
